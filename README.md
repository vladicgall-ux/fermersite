# Фермер Уелги — сайт

Сайт клуба рыболовов «Фермер Уелги» на озере Уелги (Кунашак, Челябинская область).

Статический сайт без сборки: `index.html`, картинки в `img/`, иконки, `manifest.webmanifest`,
`robots.txt`, `sitemap.xml`, промо-ролик в `video/`.

## Публикация

- **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `(root)`.
- **Любой хостинг:** загрузить содержимое репозитория в корневую папку сайта.

Домен: `fermeryelgi.ru`.
